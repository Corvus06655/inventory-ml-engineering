# Data

The original project keeps its local/generated dataset files here.

The main SQLite database is `inventory.db` at the project root in the original local project. It is not committed to GitHub because the file is about 414 MB, which is above GitHub's per-file size limit.

To run the notebooks/scripts locally, place the original `inventory.db` in the project root, or set `INVOICE_DB_PATH` where supported.
